🌱 How This Works, In Plain Language

A Next.js app on Vercel, in two halves:

  • Browser half (Client Components): the garden, plants, notebook and Demo. Purchases and lessons live in localStorage, a sticky note the browser keeps for this site, so every visitor has a private garden.
  • Server half (Route Handlers): /api/coins/search and /api/prices ask CoinGecko and cache answers for about 60 seconds for everyone.
  • In the middle, one pure function, stageFor(buyPrice, currentPrice), decides how grown every plant is.

🗺️ The Core Journey Through the System

🧠 Your Question: Server vs Browser in Next.js

Server

Route Handlers in app/api/**/route.ts. They talk to CoinGecko, cache for 60 seconds, and could hold COINGECKO_API_KEY. They can't see your localStorage.

Browser

Anything with clicks, animation or localStorage, marked "use client": the garden, notebook, CoinSearch and Demo.

The trap: Next.js renders HTML on the server first, before it knows what is in your garden. Read localStorage in useEffect (after mount), not during render, or you'll get a hydration mismatch. During the build we'll trigger it on purpose, fix it, and check the Network tab to confirm the browser only calls /api/….

🌐 External Services

CoinGecko API v3 (docs)

  • GET /api/v3/search?query={q} → { coins: [{ id, name, symbol, thumb, market_cap_rank }] }
  • GET /api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd → { bitcoin: { usd: 64000.12 } }
  • No key for the public endpoint; an optional Demo key goes in the x-cg-demo-api-key header. Free, low rate limits, protected by the 60s cache.
  • Unverified: keyless access, current limits and fields. Check early in the build.

Vercel (docs): free Hobby plan, deploys from GitHub.

⚠️ Important Failure Modes
What breaksWhat you see
CoinGecko down or rate-limitedSeed with "!" and "Price couldn't be found right now." The rest still works.
Coin search fails"Couldn't reach the coin list — try again." The entry can't be saved without a coin.
Reading localStorage during renderPrevented by loading after mount; a neutral plot shows until loaded.
Corrupt saved dataEmpty garden plus a console warning, no crash.
✂️ What Was Simplified and Why
  • localStorage instead of a database or accounts. Multi-device is deferred.
  • Prices fetched on open, with no streaming or background refresh.
  • Demo uses a simulated price, clearly tinted and labelled; the growth logic is real.
  • Hand-drawn SVG instead of a game engine.
  • USD only.
